# Criticality metrics: applicability to the PufferDrive coordination pipeline

Auto-generated by `generate_applicability_doc.py` from the `EXACT_METRICS` / `APPROXIMATE_METRICS` / `NOT_APPLICABLE` dicts in `criticality_metrics.py`. Re-run that script after editing those dicts -- do not hand-edit this file.

Source survey: Westhofen, Neurohr, Koopmann et al. (2022), *Criticality Metrics for Automated Driving: A Review and Suitability Analysis of the State of the Art*, Archives of Computational Methods in Engineering. https://doi.org/10.1007/s11831-022-09788-7 (43 metrics across 8 categories).

**Summary: 11 exact, 8 approximate (documented assumption), 21 not applicable to this pipeline's state budget (ego + nearest-agent distance/closing-speed/TTC/speed, plus the policy's own discrete action distribution -- no lane geometry, no vehicle footprints/mass, no reaction-time model, no full multi-agent trajectories).**

## Time-Scale (16)

| Metric | Status | Notes |
|---|---|---|
| ET | Not applicable | needs a defined conflict area (CA) -- a lane/road-geometry construct not present in the saved packs. |
| PET | Not applicable | same CA requirement as ET, plus needs the *other* agent's own entry/exit times for that CA, i.e. its full trajectory (only its distance/closing state is stored). |
| PTTC | Not applicable | assumes actor A1 moves at constant velocity while only A2 decelerates, needing A2's acceleration in isolation; the pipeline only ever measures the *relative* closing acceleration, with no way to attribute it to one side. a_long,req/DST already cover the same 'required deceleration' family without that attribution ambiguity. |
| PrET / SPrET / TA | Not applicable | needs a per-actor Dynamic Motion Model predicting future trajectories and an explicit predicted-path intersection point; only the current reduced state (distance, closing speed, TTC) is available, not full predicted paths for both actors. |
| TET | Exact | Time Exposed TTC -- generic threshold-crossing integral over ttc_traj. |
| THW | Exact | Time Headway == min_dist_traj / speed_traj. |
| TIT | Exact | Time Integrated TTC -- generic margin integral over ttc_traj. |
| TTB | Approximate | uses a fixed maximum-braking maneuver model (a_max = env's own action-space bound) as TTM's required 'brake' maneuver model, rather than a calibrated driver/vehicle braking model. |
| TTC | Exact | Time To Collision == the simulator's own ttc_traj / ep_min_ttc (already computed by nearest_from_states in rollout.py). |
| TTCE | Exact | Time To Closest Encounter == argmin(min_dist_traj) * dt. |
| TTS / TTK / TTR / generic TTM | Not applicable | TTB (TTM's maneuver='brake' case) is implemented using the env's own max-deceleration bound as the maneuver model. TTS (maneuver='steer') needs the same lateral signal missing for a_lat,req. TTK (maneuver='kickdown') is directional (only meaningful when approached from behind, which the packs don't distinguish). TTR = max over {brake,steer,kickdown}; with only TTB reliably defined it would just collapse to TTB, so it's not reported separately. |
| WTTC | Approximate | substitutes a single worst-case constant extra closing-acceleration (2x the env's max accel bound) for the paper's true reachable-trajectory-set computation. |

| Metric | Status | Notes |

| Metric | Status | Notes |
|---|---|---|
| CS (Conflict Severity) | Not applicable | explicitly NOT run-time capable per the survey itself -- requires a-posteriori identification of which timestep was an 'evasive maneuver', plus both agents' masses. |

## Acceleration-Scale (4)

| Metric | Status | Notes |
|---|---|---|
| DST (ts=0) | Exact | agrees with a_long,req at ts=0, per the survey's own note. |
| DST (ts>0) | Approximate | other agent's longitudinal speed v2 is approximated as ego_speed - closing_speed (assumes the closing-speed axis is approximately the longitudinal/car-following axis). |
| a_lat,req / STN / LatJ | Not applicable | all three need a lateral-acceleration or steering signal per timestep. common.py's action_stats_from_logits() DOES compute 'steer'/'steer_mag' from the policy logits, but rollout.py's readout_out capture map only pulls accel/p_brake/p_yield/gap_press/entropy into the saved pack -- steer was never persisted. Adding a 'steer': 'steer' entry to that dict (and re-running run_ego_readout.sh) would unlock these; not done here since it requires re-collecting rollout data. |
| a_long,req (DRAC) | Exact | closing_traj is v1_long - v2_long by construction, so the constant-acceleration special case is exact. |
| a_req (combined norm) | Not applicable | = sqrt(a_long_req^2 + a_lat_req^2); depends on a_lat,req (not applicable, see above). Reporting only the longitudinal term would silently misrepresent the combined metric, so it is omitted rather than degraded. |

## Index-Scale (10)

| Metric | Status | Notes |
|---|---|---|
| ACI | Not applicable | requires an externally supplied probabilistic causal 'collision tree' with per-branch conditional probabilities calibrated from a dedicated dataset -- not derivable from rollout packs alone. |
| AM | Exact | Accident Metric == the pack's own `collided` flag. |
| BTN | Exact | = a_long,req / a_min_brake, with a_min_brake the env's own exact action-space bound. |
| CI (Conflict Index) | Not applicable | built on top of PET (a-posteriori CA-crossing time) plus vehicle masses and approach headings at CA entry/exit -- none available. |
| CPI_deterministic | Approximate | the paper's CPI integrates P(a_req < a_min) under an externally-fitted normal distribution of a_min from empirical braking-capability studies; we don't have that calibration data, so we use the env's fixed action bound as a deterministic threshold, collapsing the metric to an indicator average rather than a smooth probability. |
| PRI | Not applicable | pedestrian-specific; needs a driver reaction-time model and a crosswalk conflict window, neither available. |
| RSS_long_violation | Approximate | implements only the longitudinal half of RSS-DS's simultaneous lateral+longitudinal violation test (no lane geometry for the lateral half); uses assumed constants (reaction time rho=1.0s, accel/brake bounds = env's action-space bound). Over-flags relative to the true RSS-DS. |
| RSS-DS (full) | Not applicable | the true metric requires a SIMULTANEOUS lateral AND longitudinal safe-distance violation; only the longitudinal half is implemented (see APPROXIMATE_METRICS['RSS_long_violation']) since no lane/lateral data exists. |
| SOI | Not applicable | requires a per-actor-type 'personal space' footprint definition and considers ALL actors' overlaps (retrospective multi-agent); packs only track the single nearest interacting agent per ego. |
| TCI | Not applicable | needs lane-relative reference positions (a following-distance reference r_x, a lateral-clearance reference r_y) derived from road geometry -- none in the packs. |

## Probability-Scale (3)

| Metric | Status | Notes |
|---|---|---|
| P-MC | Approximate | reinterpreted as an empirical Monte-Carlo estimate: the fraction of training-seed replicates (same method, same map) that collide, rather than the paper's control-input-prior integral -- both estimate the same quantity (a collision probability over stochastic realizations), just from different sources of stochasticity. |
| P-SMH | Not applicable | needs a finite set of scored hypothesis trajectories for BOTH the ego (two-track model) and the other agent (one-track model); the other agent's action distribution was never captured (only the ego policy's logits are read out). |
| P-SRS | Not applicable | needs precomputed offline Markov-chain reachability abstractions over a discretized state/input space for the other agent -- no such precomputation exists in this pipeline. |
